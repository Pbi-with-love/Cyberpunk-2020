# AGENTS.md — Cyberpunk 2020 Character Generator

Read `AGENT.md`, `PROMPT.md`, and `docs/SPEC.md` before modifying any files.

## Core Directives

1. **Follow `AGENT.md` as the architectural source of truth** and `docs/SPEC.md` as the screen, API, and acceptance-criteria contract.
2. **Pure Rules Engine (`src/rules/`):** Zero React/DOM imports, zero `any`, zero `Math.random()`. All randomness uses injectable `Rng` from `src/dice/`.
3. **Data-Driven (`src/data/`):** Load all roles, skills, stats, lifepath tables, and gear catalogs from `src/data/*.json` (generated by `seed-data/gen/build_seed.py`). Never duplicate game tables in UI code.
4. **2D Pixel Character Visualization:** Keep the 2D Pixel Character Canvas (`src/components/PixelAvatar/`) synchronized with the selected Role, BODY stat, Appearance settings (skin tone, hair style/color, clothes style/color), Lifepath Style, and installed Cyberware/Armor/Weapons.
5. **UI & Accessibility:** Modern, readable game UI with pixel/HUD accents, keyboard navigation, `<label>` on every control, `prefers-reduced-motion` support, and `data-testid` attributes matching `docs/SPEC.md`.
6. **Checkpoints:** Verify `npm run test`, `npm run lint`, `npm run build`, and `npx playwright test` pass with zero errors.
